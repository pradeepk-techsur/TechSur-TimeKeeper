# Admin_functions.xlsx

## Sheet1

| Module | Admin functions | 
| --- | --- |
| 1. User Management | Add, edit, activate, deactivate employees and contractors; assign branch, employee ID, manager, sponsor, and access role | 
| 2. Organization Management | Manage TechSur, FusionEdge, and 1DTS; configure branch-level settings and relationships | 
| 3. Project Management | Create, edit, activate, and close projects; assign owning branch, project manager, customer, contract number, and invoicing group | 
| 4. Charge Code Management | Create and manage charge codes; associate them with projects, branches, and employees; configure effective dates | 
| 5. LCAT Management | Create labor categories; associate LCATs with projects and employees; manage bill rates and effective dates | 
| 6. Employee Project Assignments | Assign or remove authorized projects, charge codes, and LCATs for each employee, including cross-branch assignments | 
| 7. Manager & Sponsor Mapping | Assign managers to employees and sponsors to contractors; configure backup approvers | 
| 8. Timesheet Administration | Search and view all timesheets; identify missing, late, rejected, and unsubmitted entries; perform authorized corrections | 
| 9. Pay Period Management | Generate semi-monthly periods; open, close, lock, unlock, and reopen periods with recorded reasons | 
| 10. Approval Management | View approval queues; reassign approvers; track approvals and rejections; prevent self-approval | 
| 11. Finance & Rate Management | Maintain bill rates, optional pay rates, effective dates, and rate histories; restrict financial visibility | 
| 12. Invoice Management | Generate invoices by project and date range; select LCAT hours; preview, finalize, and export invoices | 
| 13. Audit & Compliance | View complete histories of time changes, approvals, administrative actions, rates, and period locks | 
| 14. Excel Import & Export | Import employees, manager mappings, sponsors, projects, LCATs, rates, and charge codes; validate data before applying | 
| Security & Access Administration | Manage application roles, external contractor access, access reviews, and security settings |
