## Overall Summary

| Goal is to create a secure temperary solution to track timekeeping while jamis is down.  |  | 
| --- | --- |
| Temporary Timekeeping System – Requirements Summary |  | 
| Interim, secure timekeeping system to be deployed as quickly as possible. |  | 
| Platform & Security |  | 
| ·        Built entirely within the Microsoft environment. |  | 
| ·        Secure sign-in through Microsoft Entra ID for all TechSur users. |  | 
| ·        Secure access for external contractors who do not have TechSur Microsoft accounts. |  | 
| ·        All data secured and backed up in the Microsoft environment to support audits. |  | 
| Organization & Scale |  | 
| ·        Supports TechSur (main branch) and two sub-branches: FusionEdge and 1DTS. |  | 
| ·        Employees may charge time across branches (e.g., a TechSur employee with a FusionEdge or 1DTS charge code). | NO | 
| ·        Initial capacity of about 200 profiles, able to grow as needed. |  | 
| Time Entry |  | 
| ·        Employees enter time daily against their assigned projects, LCATs, and charge codes.  |  | 
| ·        Project, LCAT, and bill rate assignments loaded from the existing Excel files. |  | 
| ·        Employees can edit past days; every change is recorded in a full audit history. |  | 
| ·        Each entry is timestamped, and late entries are flagged automatically. |  | 
| Pay Periods & Submission |  | 
| ·        Two pay periods per month: the 1st–15th and the 16th–end of month. |  | 
| ·        Employees finalize and submit their timesheet at the end of each period. |  | 
| ·        Finance can lock a pay period once approved and reopen locked periods when needed. |  | 
| Roles & Access |  | 
| ·       Employees: view and edit only their own timesheets. |  | 
| ·       Employee Managers: view, edit, approve, or reject timesheets of their direct reports (mapping from the existing Excel file). |  | 
| ·       Contractor sponsors: approve their contractors' timesheets (mapping from the existing Excel file). |  | 
| ·        Project Controller: view status, details, and logs for all timesheets |  | 
| ·        Admin: view status, details, and logs for all timesheets, approve, reject, enter time on behalf of other employees |  | 
| ·      Finance and Admins: provision new employee and contractor accounts, map them to projects, and assign their LCATs. |  | 
| ·      Finance: contractor setup form to enter name, email, the projects and LCATs they can charge, and the bill rate for each. |  | 
| ·        No user can approve their own timesheet. |  | 
| ·        bill rates are visible only to Admins and Finance. |  | 
| Invoicing |  | 
| ·        Group related projects for invoicing; generate invoices per project for a specified date range, including employee name, LCAT , and hours charged to that LCAT by project. |  | 
| ·        Invoices follow the format of the demo invoice to be provided. |  |
